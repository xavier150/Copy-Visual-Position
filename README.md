# Copy Visual Position
The addon **Copy Visual Position** allows you to easily copy/paste the visual position of several elements in the scene, such as Objects, Bones, or Vertices, to another element in Edit Mode.

# How It Works
In Blender, go to **View3D > Tool > Copy Visual Position**.  
There are two panels:

- **One by One**: This allows you to copy and paste the visual location, rotation, and scale of a single object. You can also modify the values before applying them.

- **Packed**: This allows you to copy and paste the visual transforms of several objects.  
  This can be very useful in animation for IK/FK switching or to move a parent object without moving the children.  
  *(Due to the hierarchy of certain objects, it may sometimes be necessary to click the paste button multiple times.)*
